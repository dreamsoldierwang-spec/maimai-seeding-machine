# MCP 工具映射表 · Tool Mapping

> 本文件定义「选题角度 → 调用哪个麦当劳 MCP 工具 → 提取哪些关键字段」。
> Skill 在 Step 2 取数阶段严格按此表执行。所有字段名以 `mcd-mcp` 实际返回为准，下表为常见字段示例。

---

| 内容角度 | 顺序调用的工具 | 关键提取字段 | 成稿落点 |

## 逐工具取数要点

### campaign-calendar（活动日历）
- 返回当月营销活动，含进行中 / 往期 / 未来。
- 提取：活动名称、状态、日期区间、类型标签。
- 注意：成稿前用 `now-time-info` 校准「今天」，只把「进行中」和「未来」当可写素材，往期仅作背景。

### available-coupons（麦麦省券列表）
- 当前可领取的券。提取券名、门槛、优惠、有效期。
- 与 `query-my-coupons`（已领/已有券）对照，避免重复推荐。

### list-nutrition-foods（营养信息）
- 常见餐品营养：能量、蛋白质、脂肪、碳水、钠、钙。
- 健身角度：筛「高蛋白低脂肪」或「低能量」餐品做推荐；标注具体 kcal。

### query-meals / query-meal-detail（菜单/详情）
- 菜单含分类、餐品编码、标签；详情含套餐组成与可替换项。
- 新品角度：挑带「新品」标签或近期上架的餐品；点单攻略：利用「可替换项」做定制建议。

### query-nearby-stores（附近门店）
- 提供地址附近的门店与就餐方式（堂食/外带/麦乐送/得来速）。
- 探店角度：强调「取餐柜二维码」「得来速车道」等真实体验点。

### 派对四连（party-*）
- 必须按顺序：城市 → 门店 → 日期 → 场次。
- 1024 程序员节主题派对是强种草素材：写「怎么约、哪家有、什么时间」。

### query-my-account / query-lottery-info / mall-points-products（积分）
- 积分别浪费：提醒即将过期积分、抽奖玩法、商城兑换。
- 注意：抽奖有消耗，文案要提示「理性参与」。

---

## 取数纪律
1. **先 `now-time-info` 再取数**，避免时间错位。
2. 一次只取必要字段，控制频率（≤600 次/分钟，防 429）。
3. 取数后向用户**展示关键原始数据摘要**，确认后再成稿。
4. 任何工具未返回的数据，**不写、不编、不猜**；改用「以门店/活动页实际为准」。

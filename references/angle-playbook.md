# 选题角度玩法库 · Angle Playbook

> 七大常写角度。每个角度给出：目标人群、开场钩子、数据支撑点、情绪基调、易踩坑。
> Skill 在 Step 3「选题」阶段从此库提炼角度，Step 4 成稿时调用对应模板。

---

## 1. 省钱向（最稳的基本盘）
- **人群**：打工人、学生党、精打细算宝妈。
- **钩子**：「月底钱包空了还想吃点好的？」「这波券不领真的亏」。
- **数据支撑**：`available-coupons` + `query-my-coupons` 的券名/门槛/优惠/有效期；可算「原价 vs 到手价」反差。
- **情绪**：精明、松弛、不委屈自己。
- **坑**：别夸大优惠（如「免费」需确为 0 元），门槛与有效期必须写清。

## 2. 健身减脂向（差异化强）
- **人群**：健身党、减脂期、运动人群。
- **钩子**：「减脂期我靠麦当劳掉了 X 斤」「健身后这样吃不长胖」。
- **数据支撑**：`list-nutrition-foods` 的热量/蛋白质/脂肪/碳水；推「高蛋白低卡」组合。
- **情绪**：自律、科学、反差（快餐也能健康）。
- **坑**：不宣称「减肥功效」，只用营养数据陈述；提示「结合个人饮食计划」。

## 3. 节日向（1024 程序员节最强）
- **人群**：程序员、科技圈、年轻消费者。
- **钩子**：「1024 去麦当劳能白嫖限定周边你敢信？」「程序员的浪漫：汉堡回车键」。
- **数据支撑**：`campaign-calendar` 的当月活动 + 派对四连（party-*）的可约城市/门店/日期/场次。
- **情绪**：好玩、有梗、圈层认同。
- **坑**：派对需预约，务必写清「先查可约日期场次再下单」。

## 4. 探店向（真实感拉满）
- **人群**：本地生活爱好者、探店博主。
- **钩子**：「家附近新店开了！取餐柜 30 秒拿餐」。
- **数据支撑**：`query-nearby-stores` 的门店/距离/就餐方式；可结合 `query-meals` 点单。
- **情绪**：新鲜、便利、生活感。
- **坑**：门店信息以实时查询为准，别写「肯定有」。

## 5. 新品向（吃螃蟹）
- **人群**：美食猎奇党、打卡族。
- **钩子**：「麦当劳悄悄上新了！第一波实测」。
- **数据支撑**：`query-meals` 带新品标签的餐品 + `query-meal-detail` 套餐组成/可替换项。
- **情绪**：尝鲜、好奇、分享欲。
- **坑**：新品供应可能有区域差异，提示「以本地门店为准」。

## 6. 亲子向（家庭场景）
- **人群**：宝妈、亲子家庭。
- **钩子**：「带娃不知道吃啥？麦麦这套餐娃自己选」。
- **数据支撑**：`query-meals` 儿童餐/家庭套餐 + 营养数据（家长关注点）。
- **情绪**：省心、安心、温馨。
- **坑**：不宣称「儿童推荐」，用「家长常选」中性表述。

## 7. 夜宵 / 加班补给向（场景切片）
- **人群**：加班族、夜猫子、学生。
- **钩子**：「20:00 后加班党的救命晚餐」「麦乐送直达工位」。
- **数据支撑**：`query-meals` + `delivery-query-stores`（外送门店）+ 可用券。
- **情绪**：被懂、治愈、实在。
- **坑**：外送有配送范围与时段，提示「以可配送门店为准」。

---

## 组合玩法（出系列）
- 同一份 `campaign-calendar` 数据，可拆成「省钱篇 + 健身篇 + 节日篇」三连发，覆盖不同人群。
- 派对四连 + 附近门店 + 券，可做成「1024 程序员节一站式攻略」长图/长文。

# 示例输出 · Example Run

> 本示例演示「麦麦种草机」一次完整调用的输入与产出。
> ⚠️ 以下 MCP 数据均为 **mock 演示数据**，非真实优惠 / 活动，仅用于说明流程。

---

## 1. 调用麦当劳 MCP 取数（输入）

用户在 WorkBuddy 中已接入 `mcd-mcp`，麦麦种草机调用了 `campaign-calendar` 与 `available-coupons`，返回（节选）：

```json
{
  "campaign-calendar": {
    "month": "2026-10",
    "campaigns": [
      {"name":"1024 程序员节 · M-Code 主题活动","status":"进行中","start":"2026-10-24","end":"2026-10-26","type":"节日主题"},
      {"name":"麦麦省 · 周一会员日","status":"进行中","start":"2026-10-01","end":"2026-10-31","type":"优惠"}
    ]
  },
  "available-coupons": {
    "coupons": [
      {"name":"巨无霸套餐券","threshold":"满30","discount":"减12","validTo":"2026-10-31"},
      {"name":"麦辣鸡腿堡买一赠一","threshold":"无门槛","discount":"买1赠1","validTo":"2026-10-25"}
    ]
  }
}
```

用户选择：**平台 = 小红书，角度 = 省钱攻略，人设 = 打工人**。

## 2. 麦麦种草机产出（小红书草稿）

```
【标题】💰打工人的麦当劳省钱攻略：这波券我直接囤到月底

【正文】
又到饭点钱包空空？打工人的麦当劳省钱作业我抄好了，照着领就行。

📌 干货罗列：
• 巨无霸套餐券：满30 ｜ 减12 ｜ 有效至 10/31
• 麦辣鸡腿堡买一赠一：无门槛 ｜ 买1赠1 ｜ 有效至 10/25
• 活动：麦麦省 · 周一会员日（10/01–10/31）

💡 实操 tips：
1. 券可叠加门店活动，结算前先比价
2. 周一会员日 + 券最划算
3. 关注有效期，别让券过期

👇 互动：你们那边有这波吗？评论区蹲一个～收藏起来下次直接抄作业！

【话题标签】 #麦当劳优惠券 #薅羊毛日记 #打工人午餐 #省钱攻略 #麦当劳隐藏吃法

【配图分镜 · 3:4】
1. 封面：大字「省 X 元」+ 券截图
2. 内页：券清单截图
3. 内页：原价 vs 到手价对比
4. 结尾：互动卡「评论区蹲你那边有没有」

— 据麦当劳 MCP 公开数据生成，以门店/活动页实际为准。
```

## 3. 评委 / 用户可如何验证
- 打开 `demo/麦麦种草机-预览工作台.html` → 点「载入示例」→ 选「小红书 / 省钱」→「生成草稿」，即可看到等价输出。
- 真实使用时，将 WorkBuddy 调用 `mcd-mcp` 工具后的真实 JSON 粘贴进工作台，即可得到基于真实数据的草稿。

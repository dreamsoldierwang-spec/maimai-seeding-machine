## 配色参考（设计用，非品牌规范）

| 角色 | 色值 | 用途 |
| --- | --- | --- |
| 主红 | `#DA291C` | 标题、强调、按钮 |
| 主黄 | `#FFC72C` | 高亮、标签底、点缀 |
| 深灰文字 | `#27251F` | 正文 |
| 浅灰底 | `#F7F4EF` | 卡片背景 |
| 白色 | `#FFFFFF` | 主背景 |

> 配色取自麦当劳公开视觉印象，用于让「种草机」物料在小红书/公众号语境下有统一调性。
> 正式发布物料请自行确认不侵犯商标权。

## 字体建议
- 中文正文：系统默认无衬线（PingFang SC / Microsoft YaHei）。
- 数字 / 标题：可适度加粗，营造「利益点突出」的种草感。
- 避免与任何品牌定制字体产生混淆。

## 风格基调
- **生活感、克制、不模板化**：少堆卡片，多用真实截图 + 自制对比图。
- **利益点优先**：数字（省 X 元、X kcal）放大呈现。
- **口语化**：像朋友安利，不像广告通稿。

## 图标 / 插画
- 优先用 emoji（🍔💰🥗🔥）做轻量视觉，避免绘制官方吉祥物。
- 如需插画，采用扁平、原创、抽象风格，不与官方 IP 雷同。
